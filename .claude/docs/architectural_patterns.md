# Architectural Patterns

Patterns that recur across multiple files in this al-folio-based Jekyll site. References are
`file:line`.

## 1. Collections-based content model

Content types are Jekyll collections, each with a `_<name>/` directory and a listing page in
`_pages/`:

- Defined at `_config.yml:142-150`: `books`, `news` (default `layout: post`), `projects` — all `output: true`
- Native `posts` collection uses permalink `/blog/:title/` (`_config.yml:88`)
- Listing pages: `_pages/blog.md`, `_pages/portfolio.md`, etc.
- Archives (year/tag/category) generated by jekyll-archives-v2 (`_config.yml:245`); pagination by jekyll-paginate-v2 (`_config.yml:92`)

## 2. Layout inheritance

Layouts chain via the front-matter `layout:` key:

- Root: `_layouts/default.liquid` — full HTML document; pulls in `head.liquid`, `header.liquid`, footer/scripts
- Extend `default`: `page`, `post`, `about`, `cv`, `archive`, `book-review` (each `_layouts/<name>.liquid:2`)
- Two-level chain: `book-shelf.liquid:2` and `profiles.liquid:2` extend `page`
- Standalone/specialized: `bib.liquid` (one bibliography entry), `distill.liquid`, `none.liquid`

## 3. Parameterized Liquid includes

Partials in `_includes/` are reused with named parameters:

- `_includes/figure.liquid` — responsive/zoomable images; called with `loading`, `path`, `class`, `zoomable` (e.g. `_posts/2025-07-01-optimisation.md:16`)
- Site chrome: `head.liquid`, `header.liquid`, `footer.liquid`, `scripts.liquid`
- Content blocks: `latest_posts.liquid`, `news.liquid`, `selected_papers.liquid`, `projects.liquid`, `pagination.liquid`
- Domain subdirectories: `_includes/cv/` (list, time_table, map…), `_includes/repository/` (repo, repo_user, repo_trophies)

## 4. Data-driven content (`_data/`)

YAML files drive whole pages; edit data, not templates:

- `_data/cv.yml` → rendered by `_layouts/cv.liquid` + `_includes/cv/*` (each entry's `type` selects the include: list, time_table, nested_list, map)
- `_data/repositories.yml` (`github_users`, `github_repos`) → `_includes/repository/*`; repo card themes at `_config.yml:29-34`
- `_data/socials.yml` → social icons; `_data/venues.yml` / `_data/coauthors.yml` → bibliography formatting

## 5. Front-matter conventions

- **Posts** (`_posts/*.md`): `layout: post`, `title`, `date`, `description`, `tags`, `categories`, `thumbnail`, `featured`
- **Projects** (`_projects/*.md`): `layout: page`, `img`, `importance` (sort order), `category` (portfolio grouping), `related_publications`
- **Nav pages** (`_pages/*.md`): `permalink`, `nav: true`, `nav_order: N` control the navbar (e.g. `_pages/publications.md:2-7`)

## 6. Theming via CSS custom properties

- Light/dark implemented with `--global-*` CSS variables: light values under `:root` at `_sass/_themes.scss:7`, dark overrides below in the same file
- Toggle enabled by `enable_darkmode` (`_config.yml:384`)
- SCSS partials: `_variables.scss` (palette), `_base.scss`, `_layout.scss`, `_themes.scss`, `_cv.scss`, `_distill.scss`; compiled compressed (`_config.yml:222`)
- External JS libs (ECharts, highlight.js, MathJax) ship separate light/dark theme URLs with SRI hashes (`_config.yml:398` onward)

## 7. Publications pipeline (jekyll-scholar)

- Source: `_bibliography/papers.bib`; scholar config at `_config.yml:262-287` (APA style, grouped by year descending)
- Rendered by `{% bibliography %}` in `_pages/publications.md:18`, entry template `_layouts/bib.liquid`, search via `_includes/bib_search.liquid`
- Citation badges toggled at `_config.yml:289`; live counts fetched at build time by `_plugins/google-scholar-citations.rb` and `_plugins/inspirehep-citations.rb`
- Internal-use BibTeX keywords (abbr, abstract, …) are stripped from output via `filtered_bibtex_keywords` (`_config.yml` after badges) and `_plugins/hide-custom-bibtex.rb`

## 8. Custom Ruby plugins (`_plugins/`)

Build-time extensions, one concern per file: `external-posts.rb` (pull posts from external RSS),
`cache-bust.rb`, `download-3rd-party.rb` (vendor external assets), `google-scholar-citations.rb`,
`inspirehep-citations.rb`, `hide-custom-bibtex.rb`, `details.rb`, `file-exists.rb`,
`remove-accents.rb`.

## 9. Build-time asset optimization

- Responsive images: jekyll-imagemagick generates resized/WebP variants (ImageMagick installed in `.github/workflows/deploy.yml`); consumed by `_includes/figure.liquid`
- JS minified by jekyll-terser with `drop_console: true` (`_config.yml:237-239`)
- Unused CSS stripped post-build by purgecss in CI (`purgecss.config.js`, invoked in `deploy.yml`)
- HTML minified by jekyll-minifier in production
